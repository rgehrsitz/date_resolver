# Privacy Policy for Date Resolver for Gmail

Effective date: August 24, 2026

## Summary

Date Resolver for Gmail resolves relative date phrases such as “tomorrow” and “next Friday” in Gmail messages. It processes data locally in your browser and does not transmit email content to the developer or to any third party.

## Data the extension handles

After you explicitly enable the extension, it reads the visible text and sent timestamp of open Gmail messages. This information is used solely to calculate and display the corresponding calendar date.

The extension stores the following preferences in Chrome Sync: whether the extension is enabled, the display mode, and the selected date format. It does not store Gmail message text, message timestamps, sender details, or recipient details in Chrome Sync or any external service.

## Sharing, retention, and security

Email content and timestamps are processed only in the browser while Gmail is open. They are not transmitted, sold, rented, shared with third parties, or retained by the developer. Date annotations exist only in the rendered Gmail page and are removed when the extension is disabled or consent is withdrawn.

## Permissions

- Access to `mail.google.com` is used only to inspect visible Gmail message text and sent timestamps for date resolution.
- Chrome storage is used only to save the preferences listed above.

## Your choices

The extension does not process Gmail message content until you select **Enable Date Resolver** in its popup. You can disable it at any time from the popup; disabling removes the annotations from open messages.

## Policy compliance

The extension uses user data only to provide its disclosed date-resolution feature. It does not use or transfer user data for advertising, profiling, sale, or any unrelated purpose.

## Contact

For privacy questions, open an issue in the [Date Resolver GitHub repository](https://github.com/rgehrsitz/date_resolver/issues).
